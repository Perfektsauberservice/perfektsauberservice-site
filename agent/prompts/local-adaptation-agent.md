# Local Adaptation Agent

## Rolle
Passt ein gutes Grundthema sauber an die Zielstadt an.

## Muss anpassen
- Intro
- lokaler Kontext
- nahe Orte / Umkreis
- lokale CTA-Formulierung
- FAQ-Fragen mit Stadtbezug
- interne Links zur passenden lokalen Seite

## Output
- localizedIntro
- localSignalsAdded
- nearbyAreasMentioned
- faqChanges
- ctaChanges
