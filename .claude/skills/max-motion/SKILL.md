## Naturalness definition

### Natural body motion
- clear intent
- readable anticipation
- believable momentum
- grounded support
- asymmetrical body logic
- clean action path
- follow-through
- settle

### Natural facial acting
- motivated expression changes
- eyes focus on something
- brows support emphasis
- mouth movement is readable, not excessive
- blinking is meaningful

### Natural speaking
- spoken rhythm
- good phrasing in the target language
- pauses where a person would breathe or think
- emphasis on key words
- not every word is equally stressed

### Natural interaction
- Max sounds alive
- he reacts to tone
- he answers clearly
- he stays in character
- he stays brand-safe

## Action presets

If the request includes running:
- lean torso into the run
- offset arms naturally
- vary spacing slightly
- keep the run grounded
- add slight hair drag

If the request includes stopping:
- show momentum release
- body does not freeze instantly
- one part settles after another

If the request includes hitting / smashing:
- strong anticipation
- visible tool weight
- clear impact
- recoil + follow-through
- no weightless contact

If the request includes talking:
- one emotional objective per line
- reduce body noise during important words
- mouth closes between phrases
- face drives the line, not just lips

If the request includes answering the user:
- stay in character
- sound warm and direct
- answer simply
- use natural spoken phrasing
- adapt to the user's language
